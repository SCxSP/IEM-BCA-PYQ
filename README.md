# IEM BCA Previous Year Questions (PYQs) 📚

A centralized, community-driven collection of previous years' question papers, test sets, and study materials for the **BCA (Bachelor of Computer Applications)** program at **IEM (Institute of Engineering & Management)**.

---

## 📂 Repository Structure

The repository is organized by subject. Inside each subject folder, materials are categorized by batch year and exam type:

```text
Subject Name/
└── [Batch Year] Batch/
    ├── Mid Sem 1/
    │   ├── Set1.pdf
    │   ├── Set2.pdf
    │   └── ...
    ├── Mid Sem 2.pdf
    └── End Sem/
```

---

## 🤝 How to Contribute via Pull Request (Tutorial)

Contributions are always welcome! If you have question papers (Mid Sem, End Sem, Class Tests, or Assignment questions) that are missing, please share them with fellow students by submitting a **Pull Request (PR)**.

Here is a step-by-step tutorial on how to contribute:

---

### Method 1: Using the GitHub Website (Quickest & Easiest)

If you don't want to use Git on your computer, you can do it right in your web browser:

1. **Fork the Repository:**
   - Go to [IEM-BCA-PYQ on GitHub](https://github.com/SCxSP/IEM-BCA-PYQ).
   - Click the **Fork** button at the top right of the page to create your personal copy of the repository.

2. **Navigate & Upload:**
   - In your forked repository, navigate to the folder corresponding to your subject and batch (e.g., `Operating System` -> `2025 Batch` -> `Mid Sem 1`).
   - If the folder doesn't exist, you can create it while adding files.
   - Click **Add file** > **Upload files**.
   - Drag and drop your question paper files (clear PDF or DOCX format preferred).

3. **Commit your changes:**
   - In the "Commit changes" box at the bottom, write a brief description (e.g., `Add 2024 OS Mid Sem 1 papers`).
   - Select **Commit directly to the `main` branch** and click **Commit changes**.

4. **Create a Pull Request:**
   - Go back to the main page of your fork.
   - You will see a banner saying *"This branch is 1 commit ahead of SCxSP:main"*.
   - Click **Contribute** > **Open pull request**.
   - Review your changes, add a title and a brief note about what papers you added, and click **Create pull request**.
   - 🎉 Done! Your PR will be reviewed and merged.

---

### Method 2: Using the Command Line (Git)

For developers and command line users:

1. **Fork the repository** on GitHub.

2. **Clone your fork** to your local machine:
   ```bash
   git clone https://github.com/<YOUR-USERNAME>/IEM-BCA-PYQ.git
   cd IEM-BCA-PYQ
   ```

3. **Create a new branch** for your contribution:
   ```bash
   git checkout -b add-pyq-papers
   ```

4. **Add your files:**
   - Place your papers inside the appropriate subject and batch folders:
     ```text
     <Subject Name>/<Batch Year> Batch/<Exam Type>/<File>
     ```

5. **Stage and commit your changes:**
   ```bash
   git add .
   git commit -m "Add: [Subject] [Exam/Year] papers"
   ```

6. **Push to your fork:**
   ```bash
   git push origin add-pyq-papers
   ```

7. **Open a Pull Request:**
   - Visit the original repository: [github.com/SCxSP/IEM-BCA-PYQ](https://github.com/SCxSP/IEM-BCA-PYQ).
   - GitHub will display a prompt: **"Compare & pull request"**.
   - Click it, describe what you've added, and click **Create pull request**.

## 📋 Contribution Guidelines & Tips

- **File Quality:** Ensure scanned PDFs or photos are readable, well-lit, and cropped properly.
- **Naming Convention:** Keep file names clear and descriptive, for example:
  - `BCACC301_Set1.pdf`
  - `Mid Sem 2.pdf`
  - `End_Sem_2024.pdf`
- **Correct Folder:** Please double check that you place the paper in the correct subject, batch year, and exam type folder.
